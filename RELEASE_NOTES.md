# Release Notes for HUAWEI Map Kit Utility Library (Unofficial)

## Version 1.0.0-alpha03 - September 9, 2024

### Changes

- Remavenized with Maven Central since JCenter was decommissioned. ([#4](https://github.com/SupasinTatiyanupanwong/huawei-maps-utils/issues/4))
- In relation to the change of the hosted server, the groupId and the namespace of this library was changed to `dev.supasintatiyanupanwong.libraries.android.huawei.maps`.

## Version 1.0.0-alpha02 - December 8, 2020

### Fixes

- Fixed crash that can occur when using this library along side with the Google's analogy. ([#1](https://github.com/SupasinTatiyanupanwong/huawei-maps-utils/issues/1))

## Version 1.0.0-alpha01 - July 26, 2020

### Features

- Initial release of the HUAWEI Map Kit Utility Library (Unofficial).
- This version is equivalent to the Maps SDK for Android Utility Library version 2.0.3.
